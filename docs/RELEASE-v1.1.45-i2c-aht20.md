# v1.1.45 原版 AHT20 — 流式识别、长历史修复与草稿确认

面向原版 I2C AHT20/BMP280 语音助手，合入已经验收的通用修复；保留传感器、五个 Flash 会话及原有搜索实现。

- CUSTOM IAT 边采音边上传并实时更新文字；忙碌阶段保持时钟、音量与界面刷新，修复首次录音音量数秒为零的问题。
- 修复大段思考和长历史的 JSON 字符串长度、加载窗口与保存边界；校验失败时保留原文件，避免静默覆盖。
- 改善逐字输出、思考颜色、公式与角标显示、滚动及草稿排版缓存，减少长历史下的重复排版。
- 单 C 删字；双 C 请求清空整段，A 确认、B 取消、C 取消并继续删字。确认提示保持显示。
- MENU 二值设置短按 A 切换；多值设置继续使用 B/C 调节。

## 附件与更新

`VoiceAssistant-v1.1.45-i2c-aht20-app.bin` 仅包含应用分区，不含 NVS、SPIFFS、启动程序或分区表。它从公开空凭据配置构建，不包含开发者的网络或服务密钥。MIT 许可证适用于原创代码；字体及第三方依赖见仓库的许可证声明。

仅在确认设备为原版 ESP32-S3、16 MB Flash / OPI PSRAM，且既有 `huge_app` 分区的应用地址为 `0x10000`、大小为 `0x300000` 后，才可用应用区更新方式刷入。先备份已有 Flash；不要擦除整片，不要将应用文件写到 `0x0`。空芯片首次安装需配套启动程序与分区表，应按仓库构建说明完整构建。CAM 板请使用独立 CAM 项目。

使用 `SHA256SUMS.txt` 校验附件，`release-build.json` 记录构建与验证范围。已有 NVS 中的本地配置由设备保留；新设备需要通过串口或可信局域网配置自己的网络和服务。

## 验证范围与限制

公开源码编译成功，七组离线回归通过。对应逻辑在原版开发板完成应用写入、SPIFFS 完整性、传感器、串口按键与截图检查；用户确认音量即时变化与识别文字持续更新。公开空配置镜像没有再次实刷。完整验证区分见 [验证说明](VALIDATION.md)。

真实识别仍可能有网络和服务端延迟；UI 更新速度提升不等于识别端到端延迟已解决。数学/化学排版为常用语法子集。此次不包含 CAM 的相机、TF、多服务商搜索新流程，也不变更服务器。
