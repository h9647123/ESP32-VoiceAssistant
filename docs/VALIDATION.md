# 验证说明

## v1.1.43 当前真机

2026-10-31 在原版 I2C-AHT20/BMP280 板上编译并完成应用分区刷写，写后哈希校验通过。先保存完整 16 MB 备份并核对设备与分区，仅更新应用区域，保留 NVS、SPIFFS 和用户历史。

编译使用 Arduino ESP32 3.3.8，16 MB Flash / OPI PSRAM / huge_app / UART 控制台。设备应用文件为 2,282,992 字节，SHA-256 为 `1cd6790041fd7e9c8e1394c30ef3d7125a24db5b98b01cb0007933c8c171e3f6`。该哈希对应本地实刷构建，公开空凭据模板的构建时间/配置可能不同，不能要求二进制相同。

串口虚拟按键及状态回归结果见 [device-final-tests.json](device-final-tests.json)：五组根菜单、进入/返回、诊断列表不改变菜单、传感器控制、30 分钟上限、ASR 编辑、中英文布局宽度、时钟传感页、轮次组合键、离线检测、恢复后配置、完整回归日志无 panic。菜单行绘制函数与当时 CAM 版本一致。离线检测窗口内返回，记录约 0.562 秒。

本轮没有重新做真人语音准确率或真实长思考模型端到端测试。用户此前已确认 CAM 手感，原板收到菜单外观反馈后已改为 CAM 同款样式；公开源码的授权不应被表述成逐项新的视觉/音频验收。

## 主机测试

- [offline-tests.json](offline-tests.json)：实际 SSE/思考解析器承受 1,536,000 字节 reasoning 与 1,024,000 字节 inline-think；思考保留不超过约 8 KiB，实时排版尾部不超过 771 字节，正文上限 49,152 字节；包含 ASR 容量及常见公式样例。
- [tls-retry-tests.json](tls-retry-tests.json)：模拟 SDK `stop()` 清空证书信任，验证重试前重新配置，包含首连失败后再成功与其他守卫路径。
- [menu-draft-tests.json](menu-draft-tests.json)：菜单项目、传感器保留、思考项可见性与 ASR 草稿去重。

这些 JSON 是发布前原工作区的机器结果摘录。公开 `tools/test-host.py` 已去除私人目录与 CAM 依赖，可对当前源码重跑主要测试。原传感器驱动未改变的比较依赖本机旧源码备份，不要求用户下载私人备份复现。

v1.1.41–v1.1.42 曾完成整机 24/24 自动回归、10 次环境音采集/服务器 PCM 字节与哈希核对，以及三条配合用户实际发声的识别核对。录音底栏修复后用户反馈不再闪烁。这些是历史硬件、网络和服务状态下的结果，不能移作 v1.1.43 的新真人验收。
