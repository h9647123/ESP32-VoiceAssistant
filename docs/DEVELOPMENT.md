# 开发概览

本公开记录整理整个原版项目的主要开发阶段。历史工作区包含源码回退、交接文档、串口验收、模型/ASR 测试和设备界面检查；其中私人配置、用户会话、语音和 Flash 快照不随源码发布。

## 基础硬件与交互

原版以 ESP32-S3、ST7789 240×240 显示屏、INMP441 及三键操作构建语音问答闭环。加入 NVS 配置、SPIFFS 多会话、NTP、时钟、亮度、休眠、Wi-Fi 扫描和串口配置；环境显示发展为本次验证的 AHT20/BMP280 I2C 版本，同时源码保留 DHT 路径。

大量早期改动围绕可实际操作的显示：问答颜色、草稿/录音/联网/错误状态、菜单选择与连续滚动、信息页导航、边框与文字安全区、息屏唤醒与清空会话确认。v1.1.17 是迁移留档节点，并不是项目全部功能的起点。

## 流式回答、搜索与上下文

v1.1.24 起继续修复 HTTP chunked 与 SSE 处理。长回答受总预算、空闲超时、TLS 缓冲及思考流量影响，需要分别诊断，不能把所有 `read result` 都当作网络质量问题。后续统一流式/整包兜底预算，断流时保留已显示内容，并限制重试次数。

搜索决策曾独立于历史执行，直接使用决策输出会导致追问缺少上下文。后续将决策与正式回答拆开，让正式回答携带历史，且对 finish_reason 的截断状态明确提示。v1.1.43 使用有界思考保留和有限长度实时排版，防止思考越长越卡；超过可见输出上限会结束并报告，不能承诺无限长度回答。

## 文字与 Web 配置

中文内置字体缺少部分数学字符，项目先做字符探测与规范化，再引入 Noto 派生补充字形与小字形。上下标测宽/绘制共享规则，并将其约束在行框内，避免覆盖相邻中文。LaTeX 转换是设备可读文本转换，支持常用命令与符号，复杂分式、矩阵或未知宏不能达到桌面公式引擎效果。

Web 配置从调试页面发展为在线使用与设置入口，包含 Provider、模型、提示词、会话、显示与传感器等功能；HTML 独立在 debug_page.h，避免 Arduino 预处理器误识别 raw-string HTML 的花括号。

## ASR 与真实采音

官方 RTASR 与 IAT 2.0 使用独立配置，后加入 CUSTOM IAT 自建兼容端点。旧配置含义保留，自定义服务凭据不作为固件固定配置。火山接口保留，当前发布不宣称对其完成新一轮真人验收。

v1.1.41 的关键改动是解决板端采音本身：降低 PCM 转换增益、FreeRTOS 采音生产任务、PSRAM 缓冲、保持 I2S 时钟、录后上传、真实溢出计数与故障拒绝上传。识别文本不完整时应检查原始 PCM，而不是靠服务器后处理掩盖丢样。v1.1.42 进一步修复录音底栏闪烁。v1.1.43 将同类稳定性能力与更长 CUSTOM 录音时限回移到原版。

## 与 CAM 分支的关系

CAM 是独立工程，增加摄像头、照片选择/带图问答、相册、TF 与视频等功能。本版回移通用的菜单、动画、TLS/服务检测、思考流与文本显示改进，保留原版传感器和本地存储边界。没有将 CAM 的引脚、相机驱动或 TF 会话直接合并到原版。

两版均按用户选择使用 MIT 开源，第三方字形保留 OFL。首次公开提交是经过筛选的当前源码快照，不能据其单一提交推断只有本次修改。
